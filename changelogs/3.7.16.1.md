# AoA Changelog
#### Version
3.7.16.1
#### Release Date
6th January 2026
<hr>

# Additions
* Added Violet Skipper bestiary entry[^2]

# Changes
* Fixed the bestiary entries of Crimson Skipper, Crimson Stripefish, Charred Char, Candlefish, Dark Hatchetfish not having a period[^1]
* Changed Infernal's convertable blocks list to a tag (`aoa3:infernal_can_convert`) and added Blackstone[^7]
* Changed Killzone to only work in Nowhere to prevent abuse[^14]
* Adjusted some Precasian mob spawn weights[^15]
* Added `minecraft:needs_iron_tool` tag to AoA's storage blocks[^16]
* Added Blackstone, Basalt, and Ancient Debris to the Extraction support list[^17]

# Bug Fixes
* Fixed the game oping everyone on the server when right clicking a block. Sigh.[^3]
* Fixed Skeletron/Elite Skeletron Spawn Eggs having a bad name[^4]
* Fixed Vulcanes not showing the correct rage cost value[^5]
* Fixed Emberstone Swords having the wrong attack speed[^6]
* Fixed AoA Snipers not allowing customisation of scopes properly[^8]
* Fixed semi-auto guns not being entirely semi-auto[^9]
* Fixed Sand Giant's traps crashing the game if the Sand Giant stops targeting[^10]
* Fixed crossbows shooting with 3x the velocity they should
* Fixed AoA Crossbows not visibly charging[^11]
* Fixed AoA hostile mobs not being able to retaliate against other hostile mobs[^12]
* Fixed a weird crash with Ammo Void Pouch[^13]
* Fixed AoA snipers having the spyglass overlay rendered when scoping
